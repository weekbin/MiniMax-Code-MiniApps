# 灵签易占 (`chinese-divination`)

中国传统文化占卜 Mini App。以梅花易数起卦，按体用生克断吉凶，内置六十四卦全文与干支历法。
全部计算在本机完成：不联网，不读取包目录以外的任何文件。

界面为中文。想直接上手，看下面的**使用指南**；想看推演口径与能力披露，往下翻。

## 使用指南

### 三十秒上手

安装后对 MiniMax Code 说「打开灵签易占」。页面开在四个分区：**起卦 / 卦库 / 历法 / 卦历**。

想在对话里直接起卦，不用开页面，说一句「帮我起一卦」就行，见下面的[在对话里起卦](#在对话里起卦)。

### 怎么问才对

**第一行是重点。** 上面那个「所问何事」输入框决定了你这次问的是哪一类事，它会改变断语的侧重：

| 你写 | 认出的事类 | 应期会指向 |
| --- | --- | --- |
| 下个月这份 offer 该不该接 | 事业功名 | 巳午（相辰戌丑未） |
| 这笔投资还能不能赚 | 财运 | 申酉（相亥子丑） |
| 他会不会主动来找我 | 感情 | 亥子（相寅卯） |
| 明年春天结婚日子好不好 | 婚恋 | 寅卯（相巳午） |
| 父亲的手术要不要等 | 疾病 | 辰戌丑未（相申酉） |
| 这套房该不该买 | 房产车契 | 辰戌丑未（相申酉） |
| 下周的考试能过吗 | 学业文书 | 寅卯（相巳午） |

写具体比写「我的运势好不好」有用得多——**前者能认出事类、算出应期，后者只能退回按用卦推**。
如果你写的事实在认不出（比如「今天天气怎么样」），应用不会瞎套一个五行，会在断语里明说「未落到已知事类，
应期按用卦推」。

**问事不影响吉凶。** 同一个卦，问财和问婚，「凶」不会翻面——吉凶由卦自己的体用生克与月令旺衰决定。
变的只是应期落在哪几个月日、哪条断语更值得看。这一点是刻意的：占卜可以帮你把问题想清楚，
但不该由你写什么问题来买到一个好答案。

### 四种起法怎么选

| 你的处境 | 用哪个 | 会变卦的频率 |
| --- | --- | --- |
| 心里有个「现在到底怎么样」的疑问 | **时间起卦** | 每时辰一换（两小时） |
| 只想知道今天整体如何 | **每日一卦** | 一天一换 |
| 已经想好要问什么，想自己定个数 | **数字起卦** | 换一组数字就变 |
| 要一个跟当下完全无关的、随机的卦 | **铜钱摇卦** | 每掷一次都不同 |

前两种是**按时间取数**的，所以同一个时辰/同一天内反复起卦，必然是同一个卦——这不是程序在复读。
应用在结果卡上会写明自己的节律：当前取数依据、下一次何时变，甚至会直接告诉你「到丑时再起，将得
风山渐」。你可以看着它转。想每次都不一样，用铜钱摇卦或数字起卦。

### 数字起卦怎么用

1. 点「数字起卦」，输入框会展开。
2. 静心默念你问的事，**心里想出两个数**（不必真的想，顺手取也行）。
3. 填进去，点「起卦」。第一个数取上卦，第二个取下卦，两数之和取动爻。
4. 起完输入框会自动清空，免得你连点两次看到同一个结果而以为它写死了。

「随手取数」按钮会替你随机取两个 1–99 的数，适合你就是想快速来一卦的时候。

### 铜钱摇卦怎么用

点「铜钱摇卦」展开摇卦区，点「掷钱」六次，自初爻向上。界面会逐爻显示阴阳与老阴老阳，六爻掷完
后点「成卦解卦」。想重来点「重来」。这是四种起法里唯一每次都不同的。

### 结果页怎么看

| 位置 | 内容 |
| --- | --- |
| 卦题 | 写了所问就显示所问，没写就按起法命名（今日之卦 / 此刻之卦 / 心中之卦 / 手掷之卦） |
| 右上角 | 吉凶与体用关系（体生用、体克用、用生体、用克体） |
| 左侧 | 本卦与变卦的六爻图、卦辞、彖传、象辞；爻画左侧标六神，右侧标干支与六亲，世应用朱砂框标出，伏神用小字虚框挂在所属爻下，空破墓绝各作小标；动爻标红打叉，本卦下方引动爻的爻辞与象传 |
| 右侧 | 体卦/用卦的五行、方位、主客、六亲世应、用神（说清在哪一爻，或伏神伏在哪一爻）、月令旺衰、旬空与月破、四卦推导图、卦气消长环 |
| 断语 | 十五段，第二段是「动爻爻辞」，含卦气、六亲世应与用神三段；写了问题会多一段「所问之事」 |
| 宜 / 忌 | 体卦得势但用卦耗你时，会补一句提醒而不是只给一个干脆的「吉」 |
| 起卦依据 | 每个数怎么来的，全部摊开给你看，不藏 |
| 存入卦历 | 可以补一句批注，存进本机 |

断语里的**应期**是最实用的一段：它告诉你这件事大概在哪个地支对应的月份或日子会见端倪。

### 卦历

存下来的卦按时间倒序排在「卦历」分区，显示卦题、卦名、吉凶、时间和批注，可以单条删除。最多存 500 条。
这些只存在你自己的机器上，不上传任何地方。

### 在对话里起卦（MCP）

除了打开页面，你还能**完全不打开页面**，直接在对话里让 Agent 帮你起卦——它通过本应用注册的
MCP 端点调用本机上的推演逻辑。两种方式用的是同一套算法，结果一致。

#### 怎么确认能用

1. 本包要**装在 MiniMax Code 里**（复制到 `~/.minimax/plugins/chinese-divination/`，见下面的「安装」）。
2. **重启 MiniMax Code**，让 Host 读一遍插件目录、注册 MCP 服务器。
3. 然后直接说话就行，不用打开页面。

#### 怎么说，Agent 会怎么做

| 你说 | Agent 调用 | 关键参数 |
| --- | --- | --- |
| 帮我起一卦 / 看看现在怎么样 | `divination_cast` | `method: time`（默认，按当下时辰） |
| 今天什么日子 / 今天黄历 | `divination_almanac` | 无参数 |
| 谦卦什么意思 / 查一下水雷屯 | `divination_hexagram_lookup` | `query: 谦` |
| 掷铜钱 / 随机来一卦 | `divination_cast` | `method: coins`，本工具替你掷六次 |
| 今天这一卦 | `divination_cast` | `method: daily` |
| 我心里想着 3 和 8，起一卦 | `divination_cast` | `method: numbers`，`upper: 3` `lower: 8` |

你**不必**指定起法——Agent 会按你的话挑。想指定就直接说「用时间起卦」「掷铜钱」「按今天的日子起」。

**最重要的一点：把你问的事说出来。** Agent 会把你的原话填进 `question`，它决定事类与应期。
只说「起一卦」而不说问什么，也能起，但认不出事类，应期只能退回按用卦推。

#### 三个工具的参数与返回

**`divination_cast` — 起卦并解读**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `question` | string，≤120 字 | 所问何事。决定事类与应期，不改变吉凶 |
| `method` | `time`/`daily`/`numbers`/`coins` | 不填按 `time` |
| `upper` / `lower` | 整数 1–1e9 | 仅 `numbers` 用：取上卦 / 下卦 |

返回分两块：`content[0].text` 是给模型读的成文断语，`structuredContent` 是给程序用的结构化字段
（`method` / `question` / `topic` / `hexagram` / `changed` / `verdict` / `useGod` / `timing` /
`disclaimer`）。`useGod` 给出取了哪一亲；用神不上卦时，`hidden` 里带着伏神——`position`、
`hushen`、`feishen`、`flying` 与出伏结论 `emerges`——模型不必再从成文断语里刨这几句话。
实际返回长这样：

```text
【起法】数字起卦
【所问】下个月要不要接这个offer
所问事类：事业功名，类神五行 火。
【卦名】山天大畜（第 26 卦，⚊⚋⚋⚊⚊⚊），上卦 艮土、下卦 乾金
【变卦】火天大有（上卦 离、下卦 乾）
【爻象】初爻 静爻、二爻 静爻、三爻 静爻、四爻 老阴、五爻 静爻、上爻 静爻
【体用】体卦 艮土，用卦 乾金
【京房】艮宫二世卦，属土；世爻二爻持官鬼，应爻五爻为兄弟
【月令旺衰】当令 金，体 休、用 旺
【吉凶】凶 —— 凶：宜守
【断语】
【卦象总断】本卦山天大畜，利贞，不家食吉，利涉大川。…
【所问之事】所问归「事业功名」，类神取火。…类神火生体卦土，所问之事对你有补益。
【应期】事业功名类神属火，旺在巳午，相在辰戌丑未。…
【体用关系】体卦土生用卦金，是我耗自己去成全对方。…
（共十六段，后接宜、忌、起卦依据、免责说明）
```

**`divination_hexagram_lookup` — 查六十四卦**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `query` | string，≤40 字 | 卦名、上下卦名或关键字，如「乾」「雷」「风」。省略则返回全表 |
| `limit` | 整数 1–64，默认 8 | 返回条数上限 |
| `detail` | `brief`/`full`，默认 `brief` | `brief` 省去彖传原文（约省 45% 篇幅），`full` 全给 |

**这个工具不会为你另起一卦。** 你问「谦卦什么意思」，它给你谦卦的辞义，不会顺手给你算一卦。

默认只给卦辞与象辞——查卦多半是问「什么意思」，彖传 61 字左右是「理」的层面，
Agent 多数时候用不上，所以默认省掉，末尾会有一句提示。要原文就传 `detail: full`。

```text
匹配「谦」的卦共 1 个，如下：

【地山谦】第 15 卦，⚋⚋⚋⚊⚋⚋，上坤下艮
卦辞：亨，君子有终。
象辞：地中有山，谦；君子以裒多益寡，称物平施。
京房：兑宫五世卦（属金），世五爻持子孙，应二爻为官鬼
互卦 雷水解，错卦 天泽履，综卦 雷地豫

（以上省去了彖传原文；需要时传 detail="full" 补上。）
```

**`divination_almanac` — 查今日历法**

无参数。返回年月日时四柱干支、当前节气、月建五行、当前时辰（带时柱与吉凶）、黄黑道吉时、
建除十二神、数九。

```text
【日期】2026-09-29
【干支】丙午年 丁酉月 丙午日 戊子时
【节气】白露，月建 丁酉（金）
【当前时辰】子时（23:00 - 01:00，司命·黄道吉时）
【黄黑道吉时】子时、寅时、卯时、午时、未时、酉时
【建除十二神】收
【数九】未入数九（数九只在三九、九九两段）
```

#### 一个完整的往返

> **你**：下个月要不要接这个 offer？我有点犹豫。

Agent 调 `divination_cast`，`question` 填你的原话、`method` 用 `time`。你的话被认成「事业功名」，
类神取火，应期落在巳午。它用自己的语言把卦讲给你听——**断语文本由模型现场组织，
卦象由本应用按传统规则算出**。

> **你**：那如果不接呢？

它可以再起一卦（同一时辰仍是同一卦，若想不同就说「掷铜钱」），或换个角度用
`divination_hexagram_lookup` 查相关卦辞，也可以转向 `divination_almanac` 看日子。

分工就是这样：**本应用负责算得准，Agent 负责讲得贴合你的处境。**
本应用自己从不调用任何模型、不出站、不持有任何密钥。

#### 排障

**Agent 好像不知道有起卦这回事。**
最常见是没重启。Host 只在启动时扫一遍插件目录，MCP 服务器也是那时注册的。重启 MiniMax Code 再说。

**说「帮我起一卦」，它却没起。**
直接点一句「用梅花易数起一卦」，或说明「用灵签易占这个插件起」。随包的
`skills/divination/SKILL.md` 已经告诉它何时该起、何时只是查卦辞；遇到判断不了的情况，
你把起法说死即可。

**它没带免责说明。**
这是不该发生的——SKILL.md 里写的是每次转述卦象都必须带。你可以要求它补上。

**能不能不装就聊起卦？**
不能。页面和 MCP 都需要本包在 `~/.minimax/plugins/` 下被 Host 加载。

### 常见问题

**同一时辰起两次，结果一模一样？**
是。时间和日期是确定的数，同一个时辰当然得到同一个卦。想每次不同，用铜钱摇卦或数字起卦。

**问事真的有用吗，还是只是换个说法？**
问事决定事类与应期，不决定吉凶。同一时辰里问「换不换工作」和问「父亲手术要不要等」，
卦还是那个卦，吉凶还是大吉，但应期分别落在巳午和辰戌丑未，取象的侧重也不同。这是梅花易数本来的做法，
不是 AI 现编的。

**准不准？**
准不准取决于你自己。卦不预测未来，它把你已有的疑问摆到另一个角度，让你看清自己的处境与选择。
医疗、法律、财务等重要决定，请以专业意见为准。

**这些文字是谁写的？**
卦象按传统规则推演，是代码算的；把所有断语组织成通顺中文的是 AI。详见下面的「使用提醒」。

**我的问题记录会传到哪里？**
哪里都不传。存卦只写你自己机器上的 `context.dataDir`，应用不联网、不读包目录外的任何文件。

## 功能

**起卦 — 四法择一**

| 方式 | 原理 |
| --- | --- |
| 每日一卦 | 依今日年月日确定性推算，同一天结果不变 |
| 时间起卦 | 年支序加公历月、日为上卦，再加时支序得下卦与动爻，问当下事最合 |
| 数字起卦 | 静心默念两数，第一数为上卦，第二数为下卦，两数之和为动爻 |
| 铜钱摇卦 | 三枚铜钱掷六次，自初爻向上；六为老阴、七少阳、八少阴、九老阳，六与九为动爻 |

**解卦 — 体用生克**

动爻所在经卦为体卦（我），另一经卦为用卦（事）。用生体最吉，体克用与比和为吉，体生用为泄，
用克体为受制。断语再按体卦五行在当月令的旺相休囚死校正。

**四法的变卦快慢**

这一点必须讲明白，否则容易误以为结果写死：

| 起法 | 多久变一次 | 什么情况会再得同一卦 |
| --- | --- | --- |
| 铜钱摇卦 | 每掷一次 | 不会，铜钱随机 |
| 数字起卦 | 换一组数字时 | 填了相同的两个数 |
| 时间起卦 | 每时辰一换，即两小时 | 同一时辰内再起 |
| 每日一卦 | 一天一换，零点即变 | 同一天再起 |

这是术数本来的节律，不是程序在复读。因此每条断语都会在卡片上写明自己的节律：当前取数依据、
下一次何时变；对两种按时取数的，还会直接给出下一次会得到的卦（例如「到巳时再起，将得风火
家人」），你可以看着它转，不必猜。

**所问何事 — 问事定事类与应期**

写在起法上方的问题会落到一个**事类**，再由事类取**类神五行**。这是同一个卦在一天之内能解出不同
侧重的关键：

| 事类 | 类神五行 |
| --- | --- |
| 财运 | 金 |
| 事业功名 | 火 |
| 感情 | 水 |
| 婚恋 | 木 |
| 疾病 | 土 |
| 学业文书 | 木 |
| 房产车契 | 土 |
| 官讼是非 | 金 |
| 出行寻物 | 水 |

**类神只管应期与取象，不改吉凶。** 卦的吉凶仍由体用生克与月令旺衰单独推定，所以同一个卦问财与
问婚，「凶」不会翻面，变的只是应期落在哪几个月日、取象偏重哪一边。认不出事类时不硬套五行，
应期退回按用卦推算，并在断语里说明。

> 这张五行类事表是本包**自订**的类象口径，不是传世定法。梅花易数本身没有六爻那样的六亲用神，
> 本包把京房的六亲与纳甲另起一层给（见下面的「京房一层」），不拿它改体用这一层的吉凶。

**每次十五段**

卦象总断、动爻爻辞、体用关系、旺衰应期、卦气（当令主卦）、互卦（过程）、变卦（结果）、
错卦（旁支）、综卦（反求）、六亲世应、用神、主客、取象、爻位之象、方所。写了问题会多一段
「所问之事」，讲清落在哪个事类、类神与体卦的生克——也正是有了这句，用神才取得出来。

**动爻爻辞** — 真正动了的那一爻

卦辞说整卦大势，爻辞说的是动在这一爻时的处境，而那一爻正是你的问题落下的位置。三百八十四条
全部入库，解读时只引动爻那一条，不是六条全列——六条会把卦盘压成一堵字墙。爻题照传统记法
（初九、六二、上六），九与六必定与该爻阴阳相合；测试拿三百八十四条逐一比对卦象，错一位就报红。

**动爻象传** — 这一爻凭什么这么读

爻辞是断，象传是据。三百八十四条也整份入库，动爻的那一条以小字排在爻辞下方，并接在同一段
断语里，不另起一段。对校两版时翻出几处两版互有出入、有两处还与通行本相抵触：大有九四该用
「尫」（两版都作「彭」，而爻辞不作），困六三则横跨两版——「蒺藜」取自一版、「不祥」取自
另一版。这些都写进测试钉住，还有需九五的「酒食贞吉」，第二版把它扩成「需于酒食」，与所有其他
来源都不合。

两处最容易被顺手转错的字由测试钉死：损卦的「已事遄往」是已，革卦的「巳日乃革之」是巳；
噬嗑的「噬乾胏」借乾为干，而乾卦的「终日乾乾」说的是刚健，两处不能一并转成「干」。

**彖传** — 这一卦为什么长这样

卦辞说「是什么」，彖传说「凭什么」。六十四卦各有一条，入库后排在卦辞之后、象辞之前，
以一档浅色与左边线示出区别——它是解卦之辞，不是卦本身的原话。长彖传动辄百十字，
乾卦那条最长，自「大哉乾元」一路说到「万国咸宁」，把元亨利贞四字逐层拆开。

对校两版浮出十处实质差异，九处取底本：蒙卦的「初筮告」（另一版作「初噬告」）、
小畜的「健而巽」（另一版漏这四字）、革卦的「革而信之」与「巳日乃孚」都与爻辞自洽。
第十处是乾卦本身，两版一作「保和大和」、一作「保合太和」，按通行本取太和。
这些裁定都写进测试，连同繁简转换的自动推导（用简体来源与繁体底本按位对齐，导出映射表，
只保留一致对子，再人工剔掉三处由来源错字派生出的假对）一并可复现。

**起卦那三秒** — 卦是怎么成出来的

点下起卦，八卦环转起来，旁边逐字打出取数的推演。原先六爻只在结果里出现，推演全程与卦体
无关；现在卦体跟着推演一爻一爻长出来——自初爻向上，长到上爻。**动爻要等六爻都长齐了才
点红**，不能提前：起卦的意义正在于先成卦、再定哪一爻动，提前指出来等于把答案先说了。

时长的正确性由静态测试兜住：等待窗口不得短于推演预算，六爻按最小间隔排下来也必须落在窗口
之内，所以「打字打得完但卦画不完」这种事不会溜过去。系统开了「减少动效」时，六爻一次性
出现，不做生长动画。

**四卦推导** — 互、变、错、综是怎么来的

断语只说「互卦为XX」，看不到怎么互出来的。这一块把本卦摆在上面一行，四种取法的结果摆在
下一行，每一步中间标出怎么取：互卦取二三四为下卦、三四五为上卦；变卦是动爻阴阳反转；错卦
六爻阴阳全反；综卦六爻上下倒置。变卦那一格里，动的那一爻染成朱砂，一眼看出「就是它变了」。

四种取法各有分工——互卦看中间过程，变卦看最终落点，错卦看另一面，综卦看倒影。这四卦不是
四条并列的结论，是同一个问题的四个方向。取法本身由测试逐条核：互卦确为二三四、三四五，错卦
确为全反，综卦确为倒置，变卦只动该动的爻；图上画错一条，测试就报红。

**京房一层** — 六亲、世应与纳甲

这是与梅花并行的一层。梅花以「动爻所在经卦为体」讲**我跟这件事**；京房以「本卦属哪一宫、
第几世」讲六爻各自的身份——哪一爻是我（世），哪一爻是对方（应），每爻在五行生克下是谁的什么。
两套各管一段，不互相替代，所以「世应」这两个字归京房，梅花那层改称「主客」：同一段解读里
出现两个不同的世爻位会看糊涂。

八宫与世次出自《京氏易传》，本包**不抄表**：由八纯卦按爻变规则推——初爻变一世，初二变二世，
初三四变三世，初至四变四世，初至五变五世；五世卦第四爻变回为游魂；游魂卦下三爻收回来为
归魂。推导结果与传世八宫卦序逐一对撞，六十四卦全部吻合。归魂那句最容易记错：收的是游魂的
下三爻，净效果只剩第五爻被变；写成变第四、五爻的话，八个宫的归魂卦会整列变成别宫的二世卦。
测试把这条单独钉住。

纳支用沿用两千年的纳支歌诀原文（乾金甲子外壬午、坎水戊寅外戊申、艮土丙辰外丙戌、
震木庚子外庚午、巽木辛丑外辛未、离火己卯外己酉、坤土乙未外癸丑、兑金丁巳外丁亥），
八条逐一核对。**纳支随经卦走，不随卦宫走**：山水蒙属离宫（阴宫），但下艮上坎都是阳卦，
六爻便全纳阳支。六亲以本宫五行为我——生我者父母、我生者子孙、克我者官鬼、我克者妻财、
同我者兄弟，取地支五行（纳音不在此列）。

世爻一世初、二世二、三世三、四世四、五世五、本宫上爻、游魂四、归魂三；应爻与世爻**配对**
隔三位：初应四、二应五、三应六，返过来四应一、五应二、六应三。照字面写「世 + 3」的��，
本宫卦与五世卦会算到第八、第九爻去——测试专门钉这一条。

卦体上，纳甲那一列直接标在爻位右侧：干支定五行，六亲定身份，世应各用一枚朱砂框标出。
断语里对应多一段「六亲世应」，点出宫与世次、世应两爻的身份、世应之间的生克，以及动爻落在
哪一亲上（财、官、父母……各自管什么，段里一并写明）。变卦另有一套宫与世次，不沿用本卦。

**用神** — 你问的这一件事，落在哪一爻

六亲摆在那里只是摆着，落到「你问的这一件事」上才算用上了。六爻断卦第一步就是取用神：
问何事，取何亲为用神。这一条**有传世定法可依**，与上面五行类事那张自订表不是一回事。

| 所问 | 用神 | 出处 |
| --- | --- | --- |
| 财运、买卖、失物 | 妻财 | 财爻是求测者可以支配、可以到手的资源 |
| 事业功名、官司 | 官鬼 | 官鬼为职位、上司、官非；我克官鬼则我胜 |
| 学业文书、房产车契 | 父母 | 父母为文书、成绩、证照与契据 |
| 感情、婚恋 | 妻财（男占）、官鬼（女占） | 《增删卜易》「男测婚以财为用，女测婚以官为用」 |
| 疾病 | 官鬼为病症，子孙为医药 | 子孙克官鬼，子孙有力则病退 |
| 出行寻物 | 妻财 | 所求之物以财论；寻人须按关系另取，本包不替你猜关系 |

两处刻意的克制：

- **婚恋分男女，本包不替求测者认性别**，所以妻财与官鬼都列出来，由求测者对照自己那一亲
  取。择了其一就等于替他认了性别。
- **占病取两亲**（病症与医药），也是各报所在、不硬择其一。择了就等于替人认了病势。

择爻次序本包**从简为两条：动爻优先，其次取近世爻者**。传世取法更细——两爻俱动取旺相者、
俱静取旺相或临世应者，还要看日辰、旬空、墓库——那些本包不具备条件，就不硬凑一条像模像样
却无法核验的规则。近世取绝对爻位差，不带旺衰，是能核验的那条。

用神不上卦（六亲一个也不在卦里）时，传统从本宫首卦取**伏神**。这一层有明文出处，本包照做。
《增删卜易·飞伏神章第二十八》：

> 若用神不现，即以日月为用神，倘日月非用神者，则于本宫首卦寻之，因本宫首卦，父子财官六亲
> 俱全之故耳。

位置随之而定：本宫首卦里那一亲在第几爻，就伏在本卦的**同一爻之下**；压着它的那一爻是**飞神**。
书上给了两个例证，本包逐字复现——天风姤占妻财，甲寅木伏于姤卦二爻亥水之下；天山遁占子孙，
甲子水伏于遁卦初爻辰土之下。

飞伏之间的生克有四个名字，各自带断：

| 飞伏关系 | 断法 |
| --- | --- |
| 飞来生伏 | 压着它的那爻反倒生它，作吉断 |
| 伏去生飞 | 伏神一味往上供，泄气费力，付出多而收成迟 |
| 伏来克飞 | 伏神一脚踹开压着它的爻，事来得突然而急，多为不吉 |
| 飞来克伏 | 飞神死死压住伏神，所求之事受制，难以出头 |

伏神**出不出得来**是紧接着的一问。《增删卜易》列「易出有六」「终不得出有五」，本包**七条
全部核验得了**——旬空、月破、墓绝都按各自的表算。断出来只有出得来与出不来两种：旺衰只走
旺相休囚死五档，旺相必入出、休囚死必入不出，两边已穷尽全部情形。

卦体上用神那一爻另用一枚**实底朱砂**标出（世应用描边框），一眼看出「这件事在这儿」；
伏神则用小字虚框挂在所属爻下，写作「伏 丙子水妻财」。

**六神 — 日干说出的这件事的调子**

六爻卦盘上人人都会画的那一列。《卜筮全书·卷之一·启蒙节要》：

> 甲乙起青龍，丙丁起朱雀，戊日起勾陳，己日起螣蛇，庚辛起白虎，壬癸起玄武。（俱從下起至上。）

日干定的是**初爻**起哪一神，自初爻往上按固定次序转：青龙、朱雀、勾陈、螣蛇、白虎、玄武，转满
六个再回头。歌诀原文入库，与紧随其后的六行排列表逐格对撞——甲乙、丙丁、庚辛、壬癸两两同干，
共三十二格。同章的两个乾为天卦例也逐爻对过：甲子日子水子孙临青龙，戊子日同一爻临勾陈。

| 六神 | 五行 | 所主 |
| --- | --- | --- |
| 青龙 | 木 | 喜庆、喜事、贵人、酒色、正直 |
| 朱雀 | 火 | 口舌、文书、消息、是非、诉讼 |
| 勾陈 | 土 | 田土、房产、牵连、迟滞、牢狱 |
| 螣蛇 | 火 | 怪异、虚惊、缠绕、噩梦、欺诈 |
| 白虎 | 金 | 凶险、血光、伤病、丧事、威猛 |
| 玄武 | 水 | 暗昧、盗贼、隐私、暧昧、欺瞒 |

螣蛇的五行有异说，通行本多作火，亦有作阴土者。本包取**火**并写明：取土则与勾陈同，而
「虚惊」与「迟滞」本是两件事，取错便说反了。

有一条本包不许越的界，断语每次提到六神都把这句摊开：

> 吉凶全凭五行生克，情态方看六神吉凶。

六神**不参与生克、不改吉凶**，它只说这件事是什么性质、什么气氛。测试拿同一个卦在二十八天里
各起一次卦——初爻所临之神换过好几轮——吉凶必须一个字都不动。

**旬空 · 月破 · 墓绝 — 这一天的日子对每一爻做了什么**

这三样压在京房的纳甲之上，决定一爻今天还算不算数。

| | 出处 | 怎么算 |
| --- | --- | --- |
| 旬空 | 《增删卜易·旬空章第二十六》 | 歌诀六句原文入库，与算法逐句对撞。天干十位配十二支，一旬十日总有两支配不上天干，那两支便是空。 |
| 月破 | 《增删卜易》「月破者，月建冲爻之谓」 | 月建冲本爻，与「正月申破」到「十二月未破」的月表一致。 |
| 墓绝 | 《纳甲筮法讲义·生旺墓绝》 | 金墓丑绝寅、木墓未绝申、水土墓辰绝巳、火墓戌绝亥。 |

空有真假，野鹤自己分得清楚，断语照他的原话逐条落，不另立规矩：

> 旺不爲空，動不爲空，有日建動爻生扶者不爲空，動而化空、伏而旺相皆不爲空。月破爲空。
> 有卦不動爲空，爻反伏而被克爲空，真空爲空，真空卽春土、夏金、秋木、三冬逢火是真空。

**假空**是这个空不作数：旺、动、得日辰或动爻生扶、动而化空、伏而旺相任一条都能救它，
出旬或逢冲之后照旧有力。**真空**是这一旬里真没用：月破，或逢四季所空的那一行
（春空土、夏空金、秋空木、三冬空火），或伏而被克。卦体上分得清——假空作「空假」，真空作「空真」。

有一处取舍照实说明，不藏着：野鹤原文作「有卦不動爲空」，后世多本作「有氣無動爲空」，
差一个「氣」字，意思是「静卦全空」还是「静而有气者空」两样。本包取**后者**——
同段前一句「旺不爲空」若被推翻便无处容身，取前者自相矛盾。

每一爻在卦体上各有一个小标：空、破、墓、绝；右栏另有一格把当旬旬首、空亡两支与本月所破
的地支直接摊开。

**卦气 · 当令主卦** — 当月该由哪一卦说话

汉易以十二卦配十二月，称十二辟卦：复主子月、临主丑月，直到坤主亥月。它与「旺衰应期」
那条不是一回事——那条看的是五行在月令里强弱，这条看的是卦象随节气的消长。复至乾是息卦，
阳爻自初爻逐次上升；姤至坤是消卦，阴爻自初爻逐次上升。一年就这么转一圈。

断语会点出本月主卦，并说明本卦是否正在十二辟卦之中：若本卦也在息卦那一段，方向与时势
相合；若分处消长两端，就是逆着时势走，宜放缓一步。十二辟卦只占六十四卦中的十二个，其余
五十二卦不论卦气——不硬套。

**消长环** — 上面这套理论画出来是什么样子

十二辟卦是抽象的，一个环把它摊开：环分十二格，每格一卦，每格画 N 条短杠，N 就是那一月
长了几爻。复一爻长到乾六爻是阳气到底，折回姤一爻再长到坤六爻是阴气到底，走完一圈是一年。
走到对宫就是极盛——子午、卯酉那两条虚线就是标这个的。

当月那一格高亮；若你这一卦正在十二辟卦之中，环上会点一个朱砂点标出它的位置。环放在断语
之前：断语是结论，这个环是结论背后的时令坐标，先看得到形状，再读「当月主卦是哪一卦」，
就不至于只是一句话。系统开了「减少动效」时，当月格的呼吸动画会停掉。

**应期** — 事情何时应

取类神（认出事类时）或用卦（未认出时）五行的旺相之地。乾金为用卦，旺在申酉、相在亥子丑，
断语便指向申酉月与申酉日。

**爻位之象** — 动爻位置的含义

初爻事在萌芽、位未显；二爻近身而仍受制；三爻内外之交，是进退转换之关；四爻近人多惧；
五爻君位，多见贵人；上爻事至终局。

**方所** — 方位

取体卦与用卦的后天八卦方位，问寻物问路可取。

体卦得势但用卦耗你时，断语不会只给一个干脆的「吉」，而是补一句「方向可进，力气要省」。

**卦库 — 六十四卦**

可按卦名或上下卦检索，查看卦辞、彖传、象辞与互卦、错卦、综卦。

**历法**

年月日时四柱干支、十二时辰及其黄道黑道、建除十二神、二十四节气、数九、十二生肖三合六合。

**卦历**

保存的卦象存于本机，起卦后可补一句批注，按时间倒序，最多 500 条，可单独删除。写了所问就用所问
当卦题，没写则按起法命名（今日之卦 / 此刻之卦 / 心中之卦 / 手掷之卦）。

**在对话里起卦 — MCP 端点**

本包同时向 Agent 提供一个 MCP（streamable-http）端点 `/mcp/divination`，可以不打开页面直接在对话里
起卦，三个工具分别是 `divination_cast`（起卦解读）、`divination_hexagram_lookup`（检索六十四卦）、
`divination_almanac`（今日干支历法）。

**本包自己不调任何模型、不出站。** Agent 本身就是模型，由它调用本端点、再用自己的语言讲卦——
密钥、计费与上下文都留在会话里，本包只负责「算得对」。

参数、返回格式、怎么触发、排障：见上面的[在对话里起卦（MCP）](#在对话里起卦mcp)。

## 安装

将本目录（含隐藏的 `.minimax-plugin/`）复制到 MiniMax Code 插件目录，命名为
`chinese-divination/`（默认为 `~/.minimax/plugins/chinese-divination/`，具体路径见仓库根
README 的安装说明）。重启 MiniMax Code 后对 Agent 说「打开灵签易占」。

## 数据与访问

- 读取文件：仅本包内的 `miniapp/client/index.html` 与 Node 载荷目录。不读取任何 Host 文件、
  用户文件或包目录之外的路径。
- 写入文件：`context.dataDir` 下的 `readings.json`。该目录由 Host 创建并归属本 Mini App，
  内含保存的卦象与批注，按时间倒序，最多 500 条。写入先落到同目录临时文件再改名，
  中途失败不会留下半截文件。除该文件外不写任何位置。
- 网络：**无出站连接。** Node 进程不发起任何对外连接，页面不加载任何远程资源、字体或脚本，也不
  调用任何模型 API。MCP 端点只监听 Host 指定的回环地址 `context.listen`，只接受 POST。
- 子进程：不启动任何子进程。摇卦使用 Node 进程内的 `node:crypto.randomInt`。
- 凭证：不读取、不持有任何凭证，未申请 Host Connector 访问。
